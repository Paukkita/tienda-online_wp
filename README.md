# 🛍️ tienda-online_wp

Página web de comercio electrónico desarrollada con **WordPress, WooCommerce y Elementor**, que permite gestionar productos, realizar compras y efectuar pagos de forma segura mediante **Stripe**.

## 📌 Descripción

Inicialmente, este proyecto ha sido desarrollado de manera **local**, con el objetivo de comprobar y garantizar el correcto funcionamiento de la plataforma antes de su publicación.

Para la elaboración y personalización del diseño de la tienda se ha utilizado **Elementor**, permitiendo crear una interfaz moderna y adaptable.

La aplicación incluye **gestión de productos, carrito de compra, proceso de checkout y pagos mediante Stripe**.
