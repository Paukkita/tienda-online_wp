# 🛍️ tienda-online_wp

Página web de comercio electrónico desarrollada con **WordPress, WooCommerce y Elementor**, que permite gestionar productos, realizar compras y preparar un proceso de pago mediante **Stripe**.

## 📌 Descripción

Inicialmente, este proyecto ha sido desarrollado de manera **local**, con el objetivo de comprobar y garantizar el correcto funcionamiento de la plataforma antes de su publicación.

Para la elaboración y personalización del diseño de la tienda se ha utilizado **Elementor**, permitiendo crear una interfaz moderna y adaptable.

La aplicación incluye **gestión de productos, carrito de compra y proceso de checkout**. La integración con **Stripe está contemplada en el proyecto, pero actualmente no se encuentra configurada para realizar pagos reales**, ya que el proyecto tiene fines educativos y no está destinado a efectuar transacciones reales.

## 🎯 Objetivo del proyecto

El objetivo principal del proyecto es el **diseño y la elaboración funcional de una página web utilizando WordPress**, poniendo en práctica las diferentes herramientas y tecnologías empleadas en su desarrollo.

Al tratarse de un proyecto con **fines educativos**, no está prevista actualmente la adquisición de un dominio ni la publicación del proyecto en Internet.

## 🛠️ Tecnologías usadas

* **WordPress** — Gestión y desarrollo de la página web.
* **WooCommerce** — Gestión de productos, carrito y proceso de compra.
* **Elementor** — Diseño y personalización de la interfaz.
* **Stripe** — Integración prevista para el procesamiento de pagos.
* **MySQL** — Gestión de la base de datos.
